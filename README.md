# NovaPredict Fantasy — DevOps Case Study

## About the Project

NovaPredict Fantasy is a live football prediction platform where users predict match results, earn points, and compete in leagues.

This repository documents my hands-on experience building, deploying, securing, and managing the cloud infrastructure behind NovaPredict.

My focus is on **DevOps, cloud infrastructure, automation, security, and troubleshooting**.

## Tech Stack

- **Cloud:** Microsoft Azure
- **Infrastructure as Code:** Terraform
- **Containers:** Docker, Azure Container Apps
- **CI/CD:** GitHub Actions
- **Database:** PostgreSQL
- **Caching & Queues:** Redis
- **Security:** Azure Key Vault, Managed Identities, RBAC
- **Monitoring:** Azure Log Analytics, Application Insights
- **Networking & DNS:** Cloudflare

## What I've Worked On

- Building and managing Azure cloud infrastructure using Terraform.
- Containerising application services with Docker.
- Setting up CI/CD pipelines with GitHub Actions.
- Implementing identity-based access and secure secrets management.
- Configuring cloud networking, DNS, and HTTPS.
- Testing deployments, investigating failures, and improving reliability.
